Reqjet apt repository

Reqjet 0.1.6 for Debian and Ubuntu, on x64 (amd64) and Arm64.

Install Reqjet with apt, and it's updated with your other system updates (sudo apt upgrade).

The easy way: install the .deb

Download reqjet_<version>_amd64.deb (or arm64) from the download page and install it. It adds this repository for you.

sudo apt install ./reqjet_*_amd64.deb

Or set the repository up yourself

sudo install -d -m 755 /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/reqjet-archive-keyring.asc https://apt.reqjet.com/reqjet-archive-keyring.asc
sudo curl -fsSLo /etc/apt/sources.list.d/reqjet.sources https://apt.reqjet.com/reqjet.sources
sudo apt update
sudo apt install reqjet

No curl? Run sudo apt install curl first.

Stopping updates from here

Delete /etc/apt/sources.list.d/reqjet.sources. Upgrading or reinstalling Reqjet won't add it back. Uninstalling Reqjet removes the repository the package added.
